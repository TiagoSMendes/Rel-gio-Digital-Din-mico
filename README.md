# Relógio Digital Dinâmico

Relógio digital em HTML, CSS e JavaScript que mostra hora, minutos, segundos e a data por extenso em português.

## O que ele faz

- Atualiza a cada segundo, sincronizado com a virada do relógio do sistema
- Mostra a data completa (ex.: "Quinta-feira, 19 de novembro de 2026")
- Saudação e cores de fundo mudam conforme o período: manhã, tarde ou noite
- A hora também aparece no título da aba
- Responsivo: se adapta do celular ao desktop

## Rodando

Abra `Relógio-Digital/index.html` no navegador.
